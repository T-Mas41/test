# 既定の議事録フォーマット
- フォント: 日本語メイリオ、本文11pt。ヘッダー右寄せにページ番号（現在/総数）
- 構成（この順・この見出し名）:
  【基本情報】表: 開催日時／会議名／開催形式／出席者／欠席者
  1. 会議全体の概要（5行程度、1文ずつ改行）
  2. 前回宿題に対する進捗（表: 連番／担当者／対応事項／期限／進捗。無ければ「前回宿題無し」）
  3. 議事内容（議題ごとの小見出し＋簡潔な内容）
  4. 決定事項（箇条書き）
  5. 次回までの宿題（表: 連番／担当者／対応事項／期限。連番列は2桁分で最狭、対応事項列が最広）
  6. 次回会議予定
  末尾: 作成前提の注記1〜2行
